## To measure

- [ ] Display: overall size, active area and its offset, mounting holes, HDMI/USB positions, depth of the back-side controller board
- [ ] Keyboard: body size, cable exit
- [ ] Power bank: exact model number, size, port positions, and the 5V current its label lists
- [ ] Case: interior size of base and lid, wall thickness, any ribs or bosses
- [ ] Pi 5: check the official drawing for port positions (currently estimates)
